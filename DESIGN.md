# Design System: Leon Hebeisen Portfolio

## Qualitätsziele

Lighthouse, jeweils mobil und desktop, auf jeder Seite:

| Kategorie     | Ziel |
| ------------- | ---- |
| Accessibility | ≥ 95 |
| Performance   | ≥ 95 |
| SEO           | ≥ 95 |

Eine Änderung, die einen dieser Werte unter 95 drückt, ist ein Bug und wird vor dem Release nach `main` behoben.
