Umsetzung

React-19-Frontend mit TypeScript, Spring-Boot-Backend mit PostgreSQL. Seit dem Start habe ich das Frontend Datei für Datei neu strukturiert.

Frontend

Von MUI zu shadcn/ui

Migration auf shadcn/ui, Tailwind CSS und Base UI. Aufgebaut nach Atomic Design: Logik in Custom Hooks, Pages nur fürs Rendern.

Fehlerbehandlung

Drei Ebenen von Error Boundaries

Root, Page und einzeln pro TaskCard. Ein Fehler in einer Karte legt nicht mehr die ganze Seite lahm.

Auth

Google-Login mit JWT

Spring Security mit OAuth2 und OIDC über ein gemeinsames User-Interface. Danach übernimmt ein eigenes JWT.

Mobile

Eine Codebasis, drei Plattformen

Mit Capacitor wird dieselbe App zur iOS- und Android-App. Im Browser bleibt sie weiterhin nutzbar.

Was ich gelernt habe

01

Ein Login, der nach 1,8 Sekunden ablief

JWT_EXPIRATION_MS fiel auf einen falschen Standardwert zurück. Statt 30 Minuten war jedes Token fast sofort ungültig. Seither prüfe ich Defaults zuerst.

02

redirect_uri_mismatch hinter zwei Proxys

ngrok und der Vite-Proxy setzten beide Forwarded-Header, Spring baute daraus die falsche Redirect-URI. Gelöst mit forward-headers-strategy und dynamischen Redirect-URIs.
